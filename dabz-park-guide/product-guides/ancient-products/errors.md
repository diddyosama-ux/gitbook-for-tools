# Errors

#### <mark style="color:$danger;">Error: Please launch SteelSeries moment overlay(FOR GEFORCE).</mark>

* Solution: Disabled and Enabled GeForce overlay.

#### <mark style="color:$danger;">Error: Please launch SteelSeries Sonar overlay(FOR STEELSERIES).</mark>

* Solution: You need to press the SONAR's bind before launching so that the overlay works.

#### <mark style="color:$danger;">Error: If there is a flicker of menus or black screens in the game.</mark>

* Solution: Open SteelSeries -> Settings -> MOMENTS -> Capture and sound -> Turn off "ALLOW MOMENTS TO CAPTURE WHILE GAMING".

#### <mark style="color:$danger;">Error: Please disable Intel Rapid Storage Technology.</mark>

* Solution: RST must be disabled. Instructions for disabling: [https://answers.microsoft.com/en-us/windows/forum/all/uninstalling-the-intelr-rapid-storage-technology/e3c4b6d6-56ba-4ac5-be50-89843c9d9b22](https://answers.microsoft.com/en-us/windows/forum/all/uninstalling-the-intelr-rapid-storage-technology/e3c4b6d6-56ba-4ac5-be50-89843c9d9b22)

#### <mark style="color:$danger;">Error: The bind button does not work.</mark>

* Solution: Reinject, if it does not help, you need to run the overlay as an administrator.

#### <mark style="color:$danger;">Error: If no menu appears in the game or the loader closes immediately after opening.</mark>

* Solution: install the library from the link - [https://aka.ms/vs/17/release/vc\_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)

#### <mark style="color:$danger;">Error: Unsupported Frimware.</mark>

* Solution: You need to convert the disk to GPT and the BIOS to UEFI.

#### <mark style="color:$danger;">Error: 0x296.</mark>

* Solution: Need reinject.
